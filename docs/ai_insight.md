# AI Insight & Enrichment Layer

## Overview
While the core of our threat detection relies on an auditable, rule-based explainability layer (tied directly to Random Forest feature thresholds), we have integrated **Google's Gemini 2.5 Flash** to provide rich, natural-language summaries for SOC Analysts.

## What Gemini Adds
1. **Contextual Synthesization:** The rule-based layer outputs rigid logic (e.g., "High Retransmission Blindness Index: Sender is transmitting identical payload signatures..."). Gemini synthesizes this raw threshold data alongside the traffic protocol, severity, and flow metrics to produce an easily readable threat narrative.
2. **Actionable Remediation:** Gemini dynamically generates a "Recommended Action" based on the specific threat vector identified by the ML engine (e.g., suggesting specific firewall or IPS rules for DDoS, or isolating a host for Exfiltration).

## Architectural Constraints & Fallback
To ensure this system remains robust in mission-critical environments:
- **Zero-Crash Tolerance:** The `gemini_service` is designed to fail open. If the `GEMINI_API_KEY` is missing, or the Google GenAI service times out, the backend gracefully catches the exception.
- **Rule-Based Fallback:** In the event of an API failure, the UI immediately falls back to displaying the native, deterministic rule-based explanation generated by the ML engine. 
- **Transparency:** The frontend explicitly badges the insight as either "Gemini Enriched" or "Rule-Based", so analysts always know the provenance of the rationale.
